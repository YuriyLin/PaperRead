PaperRead 是以 EasyRead 為基礎深度擴充的個人研究工作區。它不僅保留雙語對照閱讀、原文座標核對、頁邊批註與 AI 問答能力，更將**「研究探索與文獻篩選」**、**「閱讀路徑與跨論文關鍵字檢索」**、**「桌面多分頁並排精讀、手寫貼紙、富文本筆記與 AI 深度技術審計」**以及**「Obsidian 結構化知識沉澱」**整合在同一個本機環境中，讓「找到論文」與「真正讀懂並整理論文」無縫銜接。

## 主要工作流程

```text
研究探索（主題搜尋 ／ 頂會期刊查詢 ／ 以文探索引用網路）
    ↓
加入候選清單（背景自動排程整理來源摘要）
    ↓
加入閱讀看板（四階段狀態拖曳管理 ＆ Quick Peek 快速檢視）
    ↓
建立閱讀路徑地圖 ／ 跨論文關鍵字雙向檢索 ／ 跨論文多維度比較
    ↓
桌面多分頁與 50/50 並排開啟論文精讀
    ├── 原頁燈箱精準定位圖表 ＆ 術語行內即時替換
    ├── 滑鼠手寫塗鴉、套索圈選 ＆ 學術貼紙自由排版
    ├── AI 智慧標註（三段強度）＆ 多模態截圖問 AI（釘選頁邊）
    └── 論文深度技術剖析報告 ＆ Mind-Elixir / Markmap 雙心智圖
    ↓
統一匯出中心（一鍵打包 Markdown / ZIP 或結構化寫入 Obsidian Vault）
```

各階段狀態彼此獨立且由使用者主導：搜尋結果不等於候選論文，加入候選不會自動塞入閱讀看板，開啟 PDF 或讀到最後一頁也不會自動竄改你的閱讀完成狀態。

## 桌面多分頁與並排閱讀（Multi-Paper Tabs & Split View）

針對同時對照多篇文獻的高頻研究情境，桌面版內建完整的多分頁管理系統：

- **多分頁標籤與快捷鍵**：文獻庫與多篇論文可在同一個視窗頂部以分頁切換，支援 `Ctrl+Tab` 循環切換、`Ctrl+W` 關閉分頁、滑鼠拖曳排序，以及 `Ctrl` / `Shift` 多選批次操作。
- **50/50 雙開並排閱讀（Split View）**：將任一論文分頁直接拖出視窗外，原視窗會自動縮放貼齊螢幕左側、新視窗貼齊螢幕右側，瞬間形成 50/50 左右並排對照視圖；將分頁拖回原視窗標籤列即可無縫合併並關閉副視窗。
- **分類自動分組與色彩標記**：開啟的論文會依所屬分類自動歸入對應色彩的標籤群組，支援群組收合、自訂改名與改色；當某分類下已無開啟分頁時，群組標籤會自動隱藏。
- **標籤列自動隱藏**：可於設定或標籤列右鍵選單開啟「自動隱藏標籤列」，平時收合以最大化垂直閱讀空間，滑鼠移近視窗頂部或拖曳分頁時自動平滑展開；開啟全螢幕燈箱或對話彈窗時，頂部標籤列亦會自動套用沉浸式遮罩與安全間距。
- **LRU 記憶體虛擬化與休眠**：背景分頁自動凍結渲染；當同時開啟超過 5 篇論文時，系統會自動休眠最久未閱讀的分頁以釋放記憶體，再次點擊時無縫恢復原先閱讀位置與狀態。

## 研究探索與跨論文關鍵字檢索

研究探索（`/research`）是 PaperRead 的文獻情報入口，結合公開書目檢索與本地文獻庫深度比對：

### 1. 主題搜尋、會議／期刊搜尋與以文探索
- **主題搜尋**：輸入研究概念或問題（如 `Long Video Understanding`、`Vision-Language Models`），並可請 AI 根據研究方向或既有論文標題／摘要提煉檢索關鍵字。
- **會議／期刊搜尋**：可單獨或一次輸入多個出版來源（如 `ICCV ECCV CVPR` 或 `MICCAI`）。系統結合 OpenAlex、DBLP 與 Crossref 書目資料，清楚區分正式會議／期刊論文與預印本（arXiv），並提供 Crossref DOI 出版紀錄核對。
- **以文探索研究**：以任一篇文獻庫或搜尋結果論文為起點，展開其「參考文獻」、「引用此文的論文」與「相關研究」，快速追蹤學術脈絡。

### 2. 跨論文關鍵字搜尋與原文定位（`/research?mode=keywords`）
- **1600px 流體雙欄與對齊佈局**：放寬主容器至 `1600px` 最大寬度，左側為固定寬度之關鍵字管理側邊欄（最適顯示約 8 個關鍵字並支援記憶位置滾動），右側為自適應展開且與左欄高度嚴格齊平的檢索結果列表。
- **中英雙向檢索與術語自動推導**：
  - 在頂部極簡輸入框新增關鍵字時，**只需輸入「中文譯名」或「英文原文」其中一項**，系統會自動檢索全庫翻譯術語表補齊對應的原文或譯名（亦可透過 `顯示名稱 / 比對詞` 語法手動指定）。
  - 檢索時同時掃描文獻庫中所有已整理論文的**中文譯文與英文原文段落**，無論單獨搜尋中文或英文皆能精準命中。
- **極簡標籤管理與分段篩選**：左側關鍵字以柔和膠囊標籤呈現，滑鼠移上（Hover）時右側淡入 `⋯` 更多操作選單（編輯、封存、移除）；支援切換「全部／僅有效／已封存」以及「符合任一（OR）／符合全部（AND）」邏輯篩選。
- **KaTeX 公式渲染與擬真螢光筆摘錄卡片**：
  - 右側每篇命中論文以手風琴（Accordion）階層呈現，預設展開前 2 個最具代表性的上下文段落，其餘可點擊「展開另外 N 個段落 ▾」收折。
  - 引文區塊完整支援 **KaTeX 數學公式安全解析與渲染**（如 `$384 \times 384$`、`$\sim 2$`、`\(...\)`），同時將命中的中英關鍵字以**擬真琥珀色螢光筆（`.rw-kw-mark`）**標記高亮。
  - 整張引文卡片皆可點擊，一鍵開啟閱讀器並精確捲動定位至該原文段落（`#b-<block_id>`）。

## 閱讀看板、Quick Peek、候選清單與已整理摘要

### 閱讀看板与 Quick Peek
- **四階段自主管理**：提供「待閱讀」、「閱讀中」、「待整理」、「已完成」四個狀態欄，支援拖曳排序、分類卡片複選、PDF 狀態與感興趣星標（★）同步篩選。閱讀進度百分比獨立記錄閱讀位置，不會自動改變看板狀態。
- **Quick Peek 快速檢視抽屜**：點擊看板卡片空白處即可從右側滑出抽屜，不離開看板即可查看完整書目、分類、閱讀狀態、進度、AI 摘要，以及分段整理的**最近筆記、最近劃線與最近問題**（點擊任一紀錄可直接跳回閱讀器對應段落），底部提供上一篇／下一篇快速切換。

### 候選清單與已整理摘要
- **候選清單**：儲存值得後續評估的論文，加入後由背景佇列依序自動整理來源摘要，避免瞬間發送大量請求。
- **已整理摘要**：摘要以 Markdown 獨立保存，支援標題、粗斜體、清單、程式碼區塊、表格與 KaTeX 公式安全渲染；可單篇或批次下載（Markdown / ZIP），或直接匯入 Obsidian Vault 的 `Research/06-論文摘要`。

## 閱讀路徑、跨論文比較與全域背景任務

- **互動式閱讀路徑（Reading Path）**：
  - 從研究主題或指定起點論文出發，將候選、參考文獻、相關研究與主題搜尋結果去重整合，依研究目標規劃閱讀順序與角色（如「基礎入門」、「方法理解」、「代表性研究」、「延伸探索」）。
  - 支援**地圖視圖与清單視圖切換**、畫布縮放平移、節點選取與閱讀順序調整；地圖中以**虛線箭頭**標示建議閱讀順序，並以**實線箭頭**標示經 OpenAlex 驗證的實際引用關係。
- **跨論文多維度比較**：選取 2 至 5 篇已完成全文整理的文獻庫論文，針對研究問題、核心方法、計算成本、實驗條件、限制與異同進行結構化對比，可匯入 Obsidian `Research/05-跨論文比較`。
- **全域非同步背景任務監控**：閱讀路徑、跨論文比較、論文深度剖析、互動心智圖與智慧標註均在後端非同步佇列執行。切換頁面或關閉彈窗不會中斷任務；頂欄與全域監控視窗會針對不同任務類型顯示專屬進度、支援隨時取消，完成時主動推播通知並提供「查看結果」直達對應視圖。

## 論文精讀、原頁燈箱與術語／關鍵字管理

PaperRead 的閱讀器（Human Reading Interface）以「雙語流暢閱讀」與「隨時核對原文證據」為核心：

- **雙語逐句對齊與排版保護**：
  - 支援「僅譯文」與「雙語對照」模式，也可以逐段點選「原」展開該段英文；句級對齊讓滑鼠懸停或點選時能立即對應中英句子。
  - 目錄抽屜採用 `level 1`～`level 6` 階梯式縮排，且目錄、頂部標題列、最近閱讀與內文全面支援 KaTeX 數學公式渲染。
  - 正文腳註（`[^n]`）與文末參考文獻（`[n]`）明確分離，點擊腳註角標直接跳轉對應註釋段落；翻譯前自動偵測並略過純空白原頁，並內建裸露 TeX 公式語法檢測與防縮水修復守衛（Repair Guard）。
- **原頁全螢幕燈箱（Page & Figure Lightbox）**：
  - 維持**「不裁切小圖」**的純淨策略，避免自動切圖不準確或破壞多子圖排版。
  - 正文中的圖表與表格佔位框（`.fig-placeholder`）：**點擊佔位框本體**會開啟右側 PDF 原頁面板並框出段落位置；**點擊佔位框右上角的「放大鏡按鈕」**則直接開啟**全螢幕高解析度原頁燈箱**。
  - 燈箱開啟時會自動依版心適讀比例縮放（約 95%），並讀取座標框**自動將捲軸置中對準該圖表或表格位置**；支援滾輪縮放（0.05x～4x）、拖曳平移、`Esc` 快速返回，且在深色模式下保持原頁白底真實色彩。
- **PDF 原頁透明文字層**：於原頁檢視面板精確還原英文單詞間距與換行，直接選取複製原文不再出現逐字斷行或漏空格。
- **左側欄「術語表」與「我的關鍵字」微互動**：
  - **術語表行內即時編輯（Inline Edit）**：去除繁瑣的重複按鈕，直接點擊術語右側的中文譯詞即可修改，按下 `Enter` 鍵立即觸發全文替換並浮現綠色「✓ 已替換」動態微互動；上方同時提供「任意詞彙全文替換」工具。
  - **我的關鍵字快速收錄**：清單頂部常駐 `[+ 新增關鍵字… (輸入後按 Enter 加入)]` 精簡輸入列，輸入中文名稱自動匹配填入英文原文比對詞（反之亦然），右下角提供「前往跨論文搜尋 ↗」快捷入口。

## 手寫註記、貼紙素材庫與富文本筆記（Tiptap + Markmap）

### 1. 正文手寫註記與套索工具（Ink Layer）
- 在正文上方提供獨立手寫塗鴉層，支援多色畫筆、筆刷粗細滑桿、**智慧橡皮擦**、**自由套索圈選（Freehand Lasso）**與多行文字框插入。
- 所有筆畫與物件移動均支援 `Ctrl+Z` / `Ctrl+Y` 復原與重做，並透過離線操作佇列自動持久化儲存。

### 2. 學術與手繪貼紙素材庫（Stickers）
- 內建豐富的 **Lucide 學術圖示**（機器學習、數學、科學、重點標記、問號、警示、幾何形狀、便利貼）與 **Mega Doodles Pack 彩色手繪插畫**。
- 支援關鍵字搜尋、分類篩選、收藏夾、最近使用紀錄，以及**滑鼠雙擊圖示直接插入至目前畫面正中央**（點選下方素材時保持捲軸位置不跳動）。
- 貼紙支援 **8 控制點自由縮放**（四角等比例／自由縮放、四邊水平／垂直單軸伸縮）、旋轉、透明度調整、圖層前後順序、鎖定、綁定外部連結，以及 Lucide 圖示線條顏色與粗細自訂。

### 3. 富文本論文筆記與 Markmap 即時心智圖
- 點擊閱讀器「筆記」面板的整篇論文筆記，可開啟獨立的**富文本筆記工作區（Tiptap Editor）**。
- 支援所見即所得工具列與 Markdown 雙向即時同步，涵蓋各級標題、粗斜體、螢光高亮、待辦清單（`- [ ]`）、引用塊、程式碼區塊、**Markdown 表格**與 **KaTeX 行內／區塊數學公式**。
- 編輯器下方即時渲染 **Markmap 結構心智圖**，支援雙向游標定位跳轉（點擊心智圖節點跳至筆記對應段落）、全螢幕展開檢視以及匯出 SVG 向量圖。

## AI 深度剖析、互動心智圖、智慧標註與多模態問答

### 1. 論文深度剖析報告（Deep Technical Audit）
位於閱讀器右上角「研究脈絡」抽屜（排於「論文心智圖」與「延伸探索」之間），由 AI 通讀全文執行客觀、嚴謹的技術審計，涵蓋五大核心維度：
1. **核心假說與實證對齊**：檢驗論文宣稱的貢獻（Claim）是否有對應的實驗或定理證據（Evidence）支撐。
2. **消融實驗審計（Ablation Audit）**：盤點各模組拔除後的真實效益與是否有未驗證的組合。
3. **關鍵公式微型推導與 Toy Example**：拆解核心數學公式的物理意義、維度變化，並以極簡數值例子輔助理解。
4. **實驗條件與基線公平性審查**：檢視資料集、超參數、計算資源與 Baseline 對比是否公平。
5. **局限性與潛在盲點**：指出論文未明說的假設限制、邊界失效情境與未來可改進方向。
- 支援全螢幕詳細檢視與一鍵複製 Markdown，並可於「匯出筆記」窗口一併下載或匯入 Obsidian `Research/04-論文深度剖析`。

### 2. 互動式論文心智圖（Mind-Elixir）
- 採用 `mind-elixir-core` 互動引擎，根據論文內容自動提煉研究問題、理論框架、方法設計、核心發現、貢獻與限制。
- 支援依論文首次翻譯的目標語言動態生成對應語系心智圖，具備全螢幕平移縮放、一鍵展開／收合分支、適應視窗寬度、KaTeX 公式與 Markdown 渲染，並支援匯出高解析度 PNG 與階層大綱。

### 3. AI 智慧標註（Smart Annotations）
- 支援針對**全文**、**指定章節**或**自訂研究目的**（如「找出 3D segmentation 的方法與限制」）進行 AI 標註分析。
- **三段劃記強度**：提供「**精簡**」、「**標準**」、「**詳細**」三種強度策略，自適應控制標註密度。
- **2×4 網格化規則圖例與語意分工**：明確區分**螢光筆（整句關鍵語意）**與**底線筆（核心詞彙片語）**，並固定四色語意：
  - **黃色**：核心概念與主要主張
  - **綠色**：方法設計與實作細節
  - **藍色**：實驗證據與量化指標
  - **紅色**：研究限制、失敗案例與待解問題
- 每筆建議皆顯示原文定位、頁碼與標註理由，供使用者逐筆或批次審閱接受，絕不覆蓋手動建立的筆記。

### 4. 問 AI、剪貼簿貼圖提問與頁邊釘選
- **輕量回答模式切換**：預設為「標準回答」，點擊單一膠囊按鈕即可切換「簡明回答」（使用短句與條列整理）。
- **剪貼簿貼圖多模態提問**：支援於問 AI 輸入框直接貼上剪貼簿截圖（PNG / JPEG / WebP，每則最多 4 張），搭配多模態模型直接詢問圖表、架構圖或複雜公式細節。
- **放到頁邊與單則匯出**：每則 AI 回答卡片皆可點擊「放到頁邊」（具備跨對話歷史自動反查與錨點備援定位，穩定釘選為正文左側青色邊注），或單獨下載 Markdown／匯出至 Obsidian `03-閱讀標註/<論文>/單則回答`。

### Obsidian Vault 六大標準資料夾結構
連結本機 Obsidian Vault 後，PaperRead 會在 `Research/` 目錄下自動維護以下結構化資料夾，具備穩定 `research_id`、SHA-256 原文校驗與雙向 WikiLinks，且重新匯出時會完整保留使用者在檔案中手寫的內容區塊：

```text
<Obsidian Vault>/Research/

├── 04-論文深度剖析/      # 五維度客觀技術審計報告（<stem>-deep-analysis.md）
├── 05-跨論文比較/        # 多篇論文研究問題、方法、成本、限制與異同比較報告
└── 06-論文摘要/          # 候選清單與文獻庫整理之結構化論文摘要
```

## 模型選擇與 AI 引擎設定

可在設定中自由配置本機 CLI 工具、主流雲端 API 或本地開源模型：

| 類型 | 支援來源與說明 |
| :--- | :--- |
| **本機 CLI 引擎** | **Antigravity CLI (`agy`)**（免 API Key 自動偵測本機可用模型、支援推理強度設定與單卡即時測試）、**Claude Code**、**Codex CLI** |
| **雲端 API** | OpenAI（自動相容 `o1`、`o3-mini` 等推理模型之 `max_completion_tokens`）、Anthropic Claude、Google Gemini、DeepSeek、智譜 GLM、阿里雲百煉、Kimi、OpenRouter、Groq、Cerebras |
| **本地模型** | **Ollama**（如 `http://127.0.0.1:11434`，支援結構化 JSON 輸出與布林 `think` 參數自動適配）、**LM Studio** |
| **自訂介面** | 任意相容於 OpenAI Chat Completions 或 Responses API 之端點與中轉服務 |

當未設定 AI 模型或網路離線時，文獻庫分類、PDF 閱讀、原頁燈箱、手寫貼紙、手動劃線筆記、閱讀看板與本地關鍵字檢索仍可 100% 正常運作。

## 安裝與執行

### Windows 安裝檔
從 [PaperRead Releases](https://github.com/YuriyLin/PaperRead/releases/latest) 下載最新的 `PaperRead-Setup-x.x.x.exe`。安裝程式已完整打包 Electron 桌面外殼與 Python 後端環境，無需另外安裝 Python 或 Node.js。
> **提示**：目前安裝檔尚未使用商業程式碼簽署憑證，若 Windows SmartScreen 顯示提示，確認下載來源為本倉庫後點選「其他資訊 → 仍要執行」即可。

### macOS 安裝檔（Apple Silicon）
從 [PaperRead Releases](https://github.com/YuriyLin/PaperRead/releases/latest) 下載 `PaperRead-x.x.x-arm64.dmg`，開啟後將 PaperRead 拖曳至 `Applications` 即可。Intel Mac 請使用下方 Docker 瀏覽器版或從原始碼建置。

### Linux AppImage
從 [PaperRead Releases](https://github.com/YuriyLin/PaperRead/releases/latest) 下載 `PaperRead-x.x.x.AppImage`，賦予執行權限即可直接啟動：

```bash
chmod +x PaperRead-*.AppImage
./PaperRead-*.AppImage
```

### Docker 瀏覽器版
適合跨平臺伺服器或無原生桌面安裝需求的情境，論文庫與設定持久儲存於 `paperread-data` volume：

```bash
git clone https://github.com/YuriyLin/PaperRead.git
cd PaperRead
docker compose up -d
```

啟動後開啟 <http://localhost:8765>。亦可直接拉取 GitHub Container Registry 預建映像：

```bash
docker pull ghcr.io/yuriylin/paperread:latest
docker run -d --name paperread --restart unless-stopped -p 127.0.0.1:8765:8765 -v paperread-data:/data/PaperRead ghcr.io/yuriylin/paperread:latest
```

> **安全提醒**：若主機上執行 Ollama，可在設定中使用 `http://host.docker.internal:11434/v1`。PaperRead 無內建帳號登入機制，預設僅綁定本機 `127.0.0.1`；若需於區域網路內跨裝置使用，建議前置具備身分驗證的反向代理，或設定 `PAPERREAD_ALLOWED_HOSTS` 白名單，切勿將連接埠直接暴露於公網。

### 從原始碼執行與打包
需要 Python 3.10+、Node.js 22+（用於桌面外殼與富文本筆記元件編譯）及 PyInstaller：

```bash
git clone https://github.com/YuriyLin/PaperRead.git
cd PaperRead
python -m pip install -e .
python -m pip install pyinstaller
npm install
```

啟動本機網頁服務（預設 `http://127.0.0.1:8765`）：

```bash
python -m easyread serve --port 8765
```

啟動 Electron 桌面版（支援多分頁與雙開並排）：

```bash
npm run dev
```

打包桌面安裝檔（自動編譯筆記編輯器、Python 後端與 Electron 安裝包，輸出至 `dist/electron/`）：

```bash
npm run dist
```

## 資料位置與相容性

安裝版預設將文獻庫與設定儲存於：

- **Windows**：`C:\Users\<使用者名稱>\PaperRead`
- **macOS**：`~/PaperRead`
